# knowledge-digital-thread
Título elegido: Construcción de un Digital Thread para la Ingeniería de Sistemas basado en Tecnologías de Grafos.
Área: Ingeniería de Sistemas.
Tema: Trazabilidad del proceso de integración del software y construcción del hilo digital.
Síntoma: Falta de perspectiva general durante la integración de diferentes componentes software y dificultad a la hora de rastrear el impacto de un cambio a lo largo del ciclo de vida del desarrollo.
Causa: Ausencia de visibilidad de las relaciones entre los elementos de las distintas etapas del proceso de desarrollo de software.
Interés: Resolver este problema reducirá los problemas a largo plazo y el tiempo necesario para introducir cambios en etapas avanzadas del desarrollo.
Hipótesis: Si tenemos mejor visibilidad sobre las relaciones entre componentes entonces tendremos menos errores y retrasos en el desarrollo del sistema respecto a cómo se hace actualmente.

## Resumen
Este proyecto propone el diseño y desarrollo de una plataforma orientada a integrar el concepto de Digital Thread en la ingeniería de sistemas. Mediante la construcción de un grafo de conocimiento, la plataforma integrará al menos tres tipos de artefactos fundamentales (requisitos, modelos lógicos y casos de prueba). El sistema permitirá la entrada de estos datos, la extracción de sus relaciones y dependencias, y proporcionará una interfaz de navegación. El objetivo final es demostrar una trazabilidad extremo a extremo funcional, facilitando el análisis del impacto y mejorando la gestión del ciclo de vida del proyecto y mostrarlo de una manera abordable para el arquitecto de la solución.

## Introducción texto con las marcas (ÁREA), (SÍNTOMA), (CAUSA)…
En el ámbito de la (ÁREA) Ingeniería de Sistemas y la gestión del ciclo de vida del software, los proyectos complejos a menudo sufren una preocupante (SÍNTOMA) falta de perspectiva general durante la integración de diferentes componentes software, así como una notable dificultad a la hora de rastrear el impacto de un cambio a lo largo del ciclo de vida del desarrollo. El origen de esta situación radica en la (CAUSA) ausencia de visibilidad de las relaciones entre los elementos de las distintas etapas del proceso de desarrollo de software. Aportar una solución a este desafío resulta crucial, puesto que (INTERÉS) resolver este problema reduciría los problemas a largo plazo y el tiempo necesario para introducir cambios en etapas avanzadas del desarrollo. Con este propósito, el presente trabajo profundiza en la (TEMA) trazabilidad del proceso de integración del software y la construcción del hilo digital, partiendo de la premisa de que (HIPÓTESIS) si tenemos mejor visibilidad sobre las relaciones entre componentes, entonces tendremos menos errores y retrasos en el desarrollo del sistema respecto a cómo se hace actualmente. 

## Objetivos objetivo general + tabla OE1…OEn
**Objetivo general:** 
Desarrollar un Hilo Digital que aporte una mejor perspectiva a los desarrolladores sobre las relaciones entre componentes de un sistema a lo largo del ciclo de desarrollo para garantizar una mejor visibilidad sobre el estado del sistema.

| ID      | Objetivo Específico (OE) |
--------------------------------------
| **OE1** | Analizar las tecnologías necesarias para implementar sistemas basados en grafos. |
| **OE2** | Diseñar el modelo de datos (esquema) del grafo para representar requisitos, modelos lógicos, casos de prueba y sus relaciones. |
| **OE3** | Desarrollar conectores para las herramientas de origen elegidas. |
| **OE4** | Implementar una base de datos orientada a grafos y la lógica para enlazar los módulos, identificando sus dependencias. |
| **OE5** | Construir una interfaz de usuario interactiva para la consulta, visualización y navegación del grafo de conocimiento. |
| **OE6** | Validar la plataforma mediante un caso de estudio práctico, demostrando la trazabilidad extremo a extremo ante cambios simulados. |
